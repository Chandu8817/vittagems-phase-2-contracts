Overview

Scenarios

Each scenario runs real transactions from the right role accounts and logs every step. Run them in order for the full story.

A · Happy path

Register a $1.5M gem → DAO approves → allocate 100% to reserves → snapshot → mint 500k VGUSD → redeem 100k for USDC.

B · Asset suspended

DAO suspends a backing asset → reserves drop → controller unhealthy → a new mint is blocked by the collateral check.

C · Reinstate & revalue

DAO reinstates the suspended asset, then revalues it +20% — pool values and max mintable follow automatically.

D · Emergency pause

Pauser multisig pauses token and controller → transfers and mints revert → only the DAO admin can unpause.

E · Access control

A plain holder tries registrar, allocator, governor, settler and pauser actions — each must revert.

F · Oracle edge cases

Depeg to $0.97 changes the quote, a stale feed blocks approval, a DAO fallback price restores it.
